
# Logistik Farhan

Sistem manajemen logistik berbasis Laravel 10 & Bootstrap 5.  
Fitur utama:
- **Master Barang** (CRUD, upload & tampilkan gambar)
- **Barang Masuk** (CRUD, relasi ke master barang)
- **Barang Keluar** (CRUD, relasi ke master barang)
- **Stok Barang** (hitung otomatis: total masuk − total keluar)
